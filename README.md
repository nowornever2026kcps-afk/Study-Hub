# StudyHub v2

AI-powered student planner with tab-based navigation, Supabase Google authentication, private study data, Gemini plan proposals, and a friends-only XP leaderboard.

Start with `SETUP.md`. Run `supabase/schema.sql` in the Supabase SQL Editor, configure Google OAuth, set `GEMINI_API_KEY` as a Supabase Edge Function secret, and deploy `ai-study-manager`.
